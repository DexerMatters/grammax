# Introduction

**Grammax** is purpose-built for developers who want to build their *incremental* own compilers and language servers efficiently. The scheme of Grammax highly consists with [the design as "terraced fields"](../design/0-terraces.md). It provides a series of groundwork for developers to use the "terraced field" structure to build their own compilers, including IRs, passes, commands, and queries.

## Modules

- `grammax::scheme` provides the basic structures and traits for building compilers.
- `grammar::scheme::layers` provides three predefined layers: 
    - **Source**: The source text. It receives updates from the outside world through an [interface]().
    - **CST**: Lossless red-green tree. It is generated by parsing the source text and can be used for syntax highlighting, parsing error reporting, formatting, etc.
    - **AST**: User-defined abstract syntax tree.
- `grammar::scheme::passes` provides two predefined passes: 
    - **Parsing**: It transforms the deltas of the source text into the ones of the CST layer.
    - **Lowering**: It transforms the deltas of the CST layer into the ones of the AST layer.
